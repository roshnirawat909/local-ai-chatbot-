# Local AI Chatbot using n8n + Ollama + Llama3

## 🚀 Project Overview
Built a fully local AI chatbot workflow using n8n and Ollama without any paid APIs.

## Features
- Local AI Agent
- Offline LLM support
- Ollama integration
- Llama3 model
- AI workflow automation
- No OpenAI API required

## Tech Stack
- n8n
- Ollama
- Llama3
- AI Agents

## Setup

### 1. Install Ollama
https://ollama.com

### 2. Pull Llama3
```bash
ollama pull llama3.1
```

### 3. Start Ollama
```bash
ollama serve
```

### 4. Import Workflow in n8n
Import the provided workflow JSON file.
